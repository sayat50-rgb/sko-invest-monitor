# Инвестиционный монитор СКО

Статический одностраничный дашборд для магистерского проекта о влиянии промышленного развития на экономические показатели Северо-Казахстанской области.

## Данные

- Областной временной ряд: 2010–2025 годы.
- Базовый год для полного сопоставления: 2024.
- 2025 год отмечен как предварительный.
- Районные значения показываются только там, где они подтверждены материалами проекта. Пропуски не заполняются оценками.

## Рабочий контур районов

Кнопка «Скачать шаблон» создаёт CSV для локальной загрузки процессных и результативных показателей районов. Файл обрабатывается в браузере и не отправляется на сервер.

Основные расчёты:

- готовность площадок = готовые площадки / приоритетные площадки;
- конверсия = запущенные проекты / квалифицированные контакты;
- выполнение плана = фактические частные инвестиции / план;
- частные инвестиции на жителя;
- доля решённых вопросов инвесторов.

Единый итоговый рейтинг не рассчитывается до завершения пилотного периода и согласования весов.

## Запуск

Откройте `dist/index.html` или запустите любой статический HTTP-сервер из корня проекта.
